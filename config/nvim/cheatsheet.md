# キーマップ チートシート

`<Leader>`はSpace。`q`か`<Esc>`で閉じる。`]x`の形のものは`[x`で逆方向、大文字(`]X`/`[X`)で最後/最初へ移動する。

## 移動

| キー | 動作 |
|---|---|
| `<CR>` | 画面内の位置へラベルでジャンプ(mini.jump2d。ノーマル/ビジュアル/オペレータ待ち) |
| `W` / `E` / `B` | 日本語の文節単位で次の頭/次の末尾/前の頭へ(budouxify) |
| `j` / `k` | 折り返し行を見た目どおりに上下(カウント指定時は実際の行単位) |
| `h` / `l` / 矢印キー | 行頭・行末で前後の行へ回り込む(whichwrap) |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | 左/下/上/右へカーソル移動(インサートモード) |
| `]b` / `[b` | 次/前のバッファ |
| `]h` / `[h` | 次/前の変更箇所(mini.diff。末尾で折り返す) |
| `]d` / `[d` | 次/前の診断 |
| `]q` / `[q` | 次/前のquickfix項目 |
| `]l` / `[l` | 次/前のlocation list項目 |
| `]w` / `[w` | 次/前のウィンドウ |
| `]c` / `[c` | 次/前のコメントブロック |
| `]i` / `[i` | インデントが変わる位置へ |
| `]t` / `[t` | treesitterノードの範囲を移動 |
| `]j` / `[j` | ジャンプリストを進む/戻る(現在のバッファ内) |
| `]o` / `[o` | 次/前の最近開いたファイル |
| `]f` / `[f` | 同じディレクトリの次/前のファイル |
| `]x` / `[x` | 次/前のgitコンフリクトマーカー |
| `]u` / `[u` | アンドゥ状態を進む/戻る |
| `g]` / `g[` | テキストオブジェクトの右端/左端へ移動(例: `g])`) |
| `af` / `if` | テキストオブジェクト: 関数定義(treesitter) |
| `ac` / `ic` | テキストオブジェクト: クラス(treesitter) |
| `aF` / `iF` | テキストオブジェクト: 関数呼び出し |
| `aa` / `ia` | テキストオブジェクト: 引数 |
| `ab` / `ib` | テキストオブジェクト: `()`/`[]`/`{}`のどれか |
| `aq` / `iq` | テキストオブジェクト: `"`/`'`/`` ` ``のどれか |
| `at` / `it` | テキストオブジェクト: タグ |
| `a?` / `i?` | テキストオブジェクト: 左右の区切りを入力して指定 |
| `ai` / `ii` | テキストオブジェクト: インデントのスコープ(mini.indentscope) |
| `an` / `in` / `al` / `il` | 次(n)/前(l)のテキストオブジェクトを対象にする(例: `cin)`) |

## ヤンク・ペースト

| キー | 動作 |
|---|---|
| `y` | ヤンク(yanky。履歴に残り、範囲がハイライトされる) |
| `p` / `P` | カーソルの後/前にペースト(yanky) |
| `]y` / `[y` | 直前にペーストした内容をヤンク履歴の次/前に差し替え(mini.bracketed独自の履歴。ペースト直後に使う) |
| `<Leader>p` | ヤンク履歴から選んでペースト |
| `<Leader>fr` | レジスタの一覧から選ぶ |
| `gy` / `gp` | システムクリップボードへコピー/から貼り付け(clipboard=unnamedplusなので普段は`y`/`p`で足りる) |
| `<C-r>` | レジスタの内容を挿入(インサートモード/コマンドライン。押すと一覧が出る) |

## バッファ

| キー | 動作 |
|---|---|
| `<Tab>` / `<S-Tab>` | 次/前のバッファ |
| `<Leader>bn` / `<Leader>bp` | 次/前のバッファ |
| `<Leader>bd` | バッファを閉じる |
| `<Leader>bx` | バッファを強制的に閉じる(未保存の変更を破棄) |
| `<Leader>bo` | 現在以外のバッファをすべて閉じる |
| `<Leader>q` | バッファとウィンドウを閉じる(最後のバッファならNeovimを終了) |
| `:BufDelete` | ウィンドウ配置を崩さずにバッファを閉じる(mini.bufremove) |
| `<C-s>` | 保存してノーマルモードへ(ノーマル/ビジュアル/インサート) |
| `<C-c>` | ノーマルモードへ戻って保存(インサートモード) |
| `<C-w>` | ウィンドウ操作(押すと一覧が出る) |
| `<Leader>tt` | フローティングターミナルの表示切替 |
| `<Leader>tc` | 新しいフローティングターミナルを作る |
| `<Leader>tn` / `<Leader>tp` | 次/前のフローティングターミナル |

## 検索

| キー | 動作 |
|---|---|
| `<Leader>ff` | ファイル検索(隠しファイル・gitignore対象も含む) |
| `<Leader>fg` | grep検索(入力のたびに再検索) |
| `<Leader>fb` | 開いているバッファから選ぶ |
| `<Leader>f/` | 現在のバッファの行を絞り込み検索 |
| `<Leader>fd` | 診断の一覧 |
| `<Leader>fh` | 最近開いたファイル |
| `<Leader>fw` | 現在のファイルのディレクトリをファイラー(mini.files)で開く |
| `<Leader>yf` | yaziをフロートで開き、選んだファイルを開く |
| `<Leader>un` | 通知の履歴 |
| `<Leader>?` | このチートシートを開く |
| `<Esc><Esc>` | 検索ハイライトを消す |
| `<C-n>` / `<C-p>` | ピッカー: 候補の下/上へ |
| `<CR>` | ピッカー: 選んで開く |
| `<C-s>` / `<C-v>` / `<C-t>` | ピッカー: 水平分割/垂直分割/タブで開く |
| `<C-x>` / `<C-a>` / `<M-CR>` | ピッカー: 候補をマーク/すべてマーク/マークしたものを開く |
| `<C-Space>` | ピッカー: 今の結果をさらに絞り込む |
| `<Tab>` / `<S-Tab>` | ピッカー: プレビュー/詳細の表示切替 |
| `<Esc>` | ピッカー: 閉じる |
| `l` / `h` | ファイラー: ディレクトリに入る・ファイルを開く/親へ戻る(`L`/`H`は入ると同時に閉じる・さらに戻る) |
| `=` | ファイラー: バッファで編集した作成・削除・名前変更を反映 |
| `g?` / `q` | ファイラー: ヘルプ/閉じる |
| `<C-n>` / `<C-p>` | 補完メニュー表示中は候補選択、それ以外は履歴移動(コマンドライン) |

## LSP

| キー | 動作 |
|---|---|
| `<Leader>ld` | 定義へ移動 |
| `<Leader>lr` | 参照の一覧 |
| `<Leader>li` | 実装の一覧 |
| `<Leader>lt` | 型定義へ移動 |
| `<Leader>lo` | ファイル内のシンボル一覧 |
| `<Leader>lw` | ワークスペースのシンボル一覧 |
| `<Leader>ln` | リネーム |
| `<Leader>la` | コードアクション(ノーマル/ビジュアル) |
| `<Leader>lf` | フォーマット |
| `<Leader>lh` | インレイヒントの表示切替 |
| `K` | カーソル下の説明を表示(Neovim標準) |
| `<C-w>d` | カーソル下の診断を表示 |
| `\d` | 診断の表示切替 |
| `<Tab>` / `<S-Tab>` | 補完候補を選ぶ(インサートモード、補完メニュー表示中) |
| `<CR>` | 選んだ候補で確定(未選択なら改行) |
| `<C-Space>` | 補完を手動で開く(インサートモード) |
| `<M-Space>` | LSPを使わない補完を開く(インサートモード) |
| `<C-f>` / `<C-b>` | 補完の説明・シグネチャを下/上へスクロール(インサートモード) |
| `<C-l>` / `<C-h>` | 次/前のプレースホルダへ(スニペット展開中のみ) |
| `<C-c>` | スニペットを終了(スニペット展開中のみ。ノーマルモードに戻っても終了する) |

## Git

| キー | 動作 |
|---|---|
| `]h` / `[h` | 次/前の変更箇所(末尾で折り返す) |
| `]H` / `[H` | 最後/最初の変更箇所 |
| `gh` | 範囲の変更をステージ(オペレータ。`ghgh`で変更箇所全体) |
| `gH` | 範囲の変更を取り消す(オペレータ) |
| `]x` / `[x` | 次/前のコンフリクトマーカー |
| `<Leader>gb` | 現在のファイルのコミット履歴 |
| `<Leader>gl` | 全体のコミット履歴 |
| `:Git` | gitコマンドを実行(mini.git) |

## 編集・囲み

| キー | 動作 |
|---|---|
| `sa{motion}{char}` | 囲みを追加(例: `saiwb`。ビジュアルモードでは`sa{char}`) |
| `sd{char}` | 囲みを削除 |
| `sr{old}{new}` | 囲みを置き換え |
| `sf` / `sF` | 右/左の囲みへ移動 |
| `sh` | 囲みをハイライト |
| `sdn` / `sdl`など | 末尾に`n`/`l`を付けると次/前の囲みが対象 |
| `(` `[` `{` | 囲み文字: 内側にスペースあり |
| `)` `]` `}` | 囲み文字: スペースなし |
| `b` / `B` | 囲み文字: `()` / `( )` |
| `r` / `R` | 囲み文字: `[]` / `[ ]` |
| `c` / `C` | 囲み文字: `{}` / `{ }` |
| `j` / `k` | 囲み文字: `「」` / `『』` |
| `cl` / `r` | 1文字置き換え(`s`は囲みのプレフィックスのため) |
| `<C-_>` | コメント切替(Ctrl+/。ノーマルで行、ビジュアルで選択範囲) |
| `gc{motion}` / `gcc` | コメント切替(オペレータ/行) |
| `gr{motion}` / `grr` | レジスタの内容で置き換え |
| `gx{motion}` / `gxx` | 2回指定した範囲を入れ替え |
| `gm{motion}` / `gmm` | 範囲を複製 |
| `gs{motion}` | 並べ替え |
| `g={motion}` / `g==` | Luaの式として評価して結果に置き換え |
| `gX` | カーソル下のURL・パスを開く(`gx`は入れ替えに使用) |
| `ga` / `gA` | 整列(`gA`はプレビュー付き) |
| `<Leader>s` | 引数を1行/複数行に切替(ノーマル/ビジュアル) |
| `<M-h>` / `<M-j>` / `<M-k>` / `<M-l>` | 行・選択範囲を左/下/上/右へ移動 |
| `go` / `gO` | 下/上に空行を追加 |
| `jk` / `jj` / `kj` | ノーマルモードへ戻る(インサートモード) |
| `,` | `, `を入力(インサートモード) |
| `\w` / `\n` / `\r` / `\s` / `\l` | 折り返し/行番号/相対行番号/スペルチェック/不可視文字の表示切替 |
