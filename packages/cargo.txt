# cargo でインストールするツール
# 書式: <crate名> [cargo install に渡す追加引数]
#   - 追加引数なし → crates.io から cargo binstall (ビルド済みバイナリがあれば使い、無ければビルド)
#   - 追加引数あり → cargo install --locked <追加引数> <crate名> (git 等からビルド)
#     --locked はリポジトリの Cargo.lock どおりに依存を固定する (bootstrap.sh 側で付与)
#
# mise は公式インストーラ (mise.run) で入れるためここには含めない。
